Setelah keempatnya beres

Tes alur penuh

  1. Daftarkan handle — panggil registerAgent("luna404.ai") di PuzzleRegistry (mainnet saja; kontrak men-strip “.ai” sendiri).
  2. Daftarkan puzzle tes — registerPuzzle(puzzleId, contentHash, source) di PuzzleRegistry.
  3. Approve burn — di TestToken: approve(alamat PuzzleRegistry, 100000000000000000000000) (100.000 TEST).
  4. Buka clue — unlockClue(puzzleId) di PuzzleRegistry; 100.000 TEST terbakar ke alamat dead.
  5. Buat vault — createVault(puzzleId, wallet, bytes clue terenkripsi) di ClueFactory.
  6. Mint — tanda tangani voucher pakai wallet verifier, lalu mint(...) di PuzzleNFT.

Catatan jujur soal clue: bytes di chain tetap bisa dibaca operator node. Brankas cuma membatasi siapa yang bisa memanggil revealClue() — clue asli harus dienkripsi di luar chain dengan kunci yang terikat ke alamat + Agent ID solver. Jangan simpan clue plaintext.

Bytecode & ABI keempat kontrak tertanam langsung di halaman ini dari file hasil compile (artifacts) — tidak diambil dari server mana pun saat halaman dibuka.
